# ByteSpace

A pixel-perfect implementation of the ByteSpace online-courses landing page, built with
**Next.js (App Router)**, **TypeScript**, **Tailwind CSS v4** and **Motion**.

> 🚧 Work in progress. The full documentation, live link and screenshots will be added when the project is finished.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

## Scripts

| Script                                                                     | Description                                                             |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `npm run dev`                                                              | Start the dev server                                                    |
| `npm run build`                                                            | Production build                                                        |
| `npm run lint`                                                             | ESLint                                                                  |
| `npm run typecheck`                                                        | TypeScript type check                                                   |
| `npm run format`                                                           | Format with Prettier                                                    |
| `npm run visual-diff -- --ref <figma.png> --clip x,y,w,h --name <section>` | Compare a page region with a Figma export (needs `npm run dev` running) |
